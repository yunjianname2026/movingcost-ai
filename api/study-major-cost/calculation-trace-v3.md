## 复现方法

1. 从 profile 中取 `target_degree`、`tuition_position`、`target_city_type`、`housing_type`、`car_need`、`program_year`
2. 查 rules.md v3 对应表格取固定点值；住宿只查 HousingTable[tier][housing_type]，不随情景变化
3. 按情景判断汽车附加是否计入（第2节规则）
4. 按年份类型（Year1 / 中间年 / 最后一年）选择对应的一次性成本或毕业准备金是否叠加
5. 应用应急缓冲百分比，四舍五入到百位
6. 转专业延长一律作为独立压力测试数字展示，不并入基础总额
